Key-Value Store
===============

The key-value store represents the internal state of the network. It is used by applications to store data to and read from the ledger.

.. note:: The pages below describe the C++ API. The experimental :doc:`Rust SDK <../rust_api>` exposes only raw-byte maps; see :ref:`build_apps/example_rust:Handler rules`.
