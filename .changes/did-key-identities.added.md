CCF supports opt-in `did:key` node IDs and certificate-free member/user enrollment with `did_key`, including COSE signing with `--signing-did-key` and key generation with `keygenerator.sh --public-key-only`.
See [Identity IDs](doc/architecture/cryptography.rst#identity-ids) and the [atomic migration guide](doc/governance/migrating_identity_ids.rst) for compatibility and migration guidance.
