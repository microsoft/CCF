`GET` and `HEAD` `/node/ledger_chunk?since=<seqno>` no longer wait for the ledger's file operations, such as the fsync of a completed chunk, to find the committed chunk containing the seqno, so they no longer hold a request thread until those operations finish, which on network storage can take tens of seconds.
With `include_committed_prefix=true`, requests still wait for those operations when no committed chunk contains the seqno; see [Download Endpoints](doc/operations/ledger_snapshot.rst#download-endpoints).
