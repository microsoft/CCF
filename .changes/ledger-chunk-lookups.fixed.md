`GET` and `HEAD` `/node/ledger_chunk?since=<seqno>` no longer wait for the fsync of a completed ledger chunk, which can take tens of seconds on network storage, to find the committed chunk containing the seqno.
They list the ledger directory, so on network storage they can still wait while a chunk file is created, renamed or removed, and with `include_committed_prefix=true` they still wait for the ledger's file operations when no committed chunk contains the seqno; see [Download Endpoints](doc/operations/ledger_snapshot.rst#download-endpoints).
